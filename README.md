🐉 Projeto DBZ

Este projeto é um site temático inspirado no universo de Dragon Ball Z, criado com o objetivo de praticar habilidades de HTML, CSS e JavaScript.
O foco é apresentar personagens originais, misturando o espírito do anime com elementos de programação, tecnologia e ficção científica.

🚀 Funcionalidades

Personagens com nomes e histórias únicas inspiradas no mundo tech

Layout estilizado com cores e elementos que remetem ao universo DBZ

Estrutura responsiva, adaptando-se a diferentes dispositivos

Organização em cards interativos com imagens e descrições

🧰 Tecnologias Utilizadas

HTML5 – Estrutura das páginas

CSS3 – Estilização visual e responsividade

JavaScript – Funcionalidades dinâmicas e interatividade (caso aplicável)

GitHub Pages – Publicação online do projeto

🎯 Objetivos

Praticar a criação de layouts temáticos e criativos

Aplicar conceitos de design responsivo e organização de conteúdo

Desenvolver um projeto visualmente atrativo que combine anime e tecnologia

🦸‍♂️ Personagens
Cyberstorm

Kael Takeda, conhecido como Cyberstorm, é um programador prodígio especializado em segurança cibernética e inteligência artificial.
Com um intelecto afiado e reflexos rápidos, domina linguagens de programação como se fossem extensões da própria mente.

CodePixie

Lía Nakamura, chamada de CodePixie, é uma programadora genial focada em algoritmos e inteligência artificial.
Ela possui um talento nato para decifrar padrões e criar sistemas inovadores que protegem dados sensíveis.

HexBlade

Ryo Tanaka, apelidado de HexBlade, é um hacker das sombras do ciberespaço.
Mestre em engenharia reversa e criptografia, une força bruta e inteligência para superar até os firewalls mais impenetráveis.

NeonPulse

Ayla Vega, ou NeonPulse, é uma prodígio da programação espacial, criada em uma estação orbital.
Ela domina linguagens de código como segunda língua e se especializa em IA e segurança cibernética.

Codebreaker

Orion Vex, conhecido como Codebreaker, é um ex-engenheiro cibernético que vive em uma estação espacial abandonada.
Seu objetivo é decifrar um código ancestral perdido há séculos, capaz de redefinir a inteligência artificial.
